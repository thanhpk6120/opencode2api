Free-model probing

Probes models whose names contain free or whose metadata reports zero price without deprecation. Tries the anonymous lane first, then a Zen key; a model is disabled only on an explicit not-found signal and rechecked after 24 hours. Transient errors never create a new disable: enabled models retry after 1 hour, disabled ones keep their original reason and retry after 24 hours. A restored or manual model stays enabled and skips automatic probing; switching back to automatic schedules a probe on the next pass. System One uses a dedicated 1+1 decision question. With auto effort, the highest probed level is shown.

SOTA / sweet-model rotation

Stick with the working model after success. On quota shortage or errors, rotate in order; OpenCode Go only.

Reuse your existing base URL and API key; set OPENAI_MODEL to an alias below. Up to 3 attempts per model on ordinary errors and up to 3 models per request; quota shortages are skipped outright.

Once output starts, the whole answer stays on one model. A mid-stream failure ends that output; the next request rotates. Models share the plan quota, so switching does not guarantee relief when the plan is exhausted.

Saving takes effect immediately; reordering never interrupts an in-flight answer. Manually picking the current model applies at once and clears that model's temporary pause.
